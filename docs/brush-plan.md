# План: всички четки, сравнени с Blender

Всяка четка се сравнява с кода на Blender (`source/blender/editors/sculpt_paint/mesh/brushes/`,
GPL — идеите се пренасят със собствен код, самият код не се копира). Взима се само това, което у нас
дава **измерима** полза; иначе се записва като „пробвано, не взето“. Всяка промяна минава:
равенство до бит между Rust и JavaScript (където четката е в ядрото), изпитването до крайност
(`test/stress.mjs`) и пълните тестове; после се пуска нова версия.

Знаци: ✅ готово · ➖ сравнено, нищо за взимане · ❌ пробвано, не взето · ⏳ предстои
